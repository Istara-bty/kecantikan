# Glow Beauty - Website Skincare & Kecantikan

## ✨ FITUR LENGKAP

### Manajemen Produk
| Fitur | Keterangan |
|-------|------------|
| Tambah Produk | Upload gambar, nama, harga, kategori |
| Edit Produk | Ubah nama, harga, kategori, ganti gambar |
| Hapus Produk | Hapus produk yang tidak diinginkan |

### Manajemen Kategori
| Fitur | Keterangan |
|-------|------------|
| Tambah Kategori | Buat kategori baru |
| Edit Kategori | Ubah nama kategori |
| Hapus Kategori | Hapus kategori (jika tidak digunakan) |

### Manajemen Testimoni
| Fitur | Keterangan |
|-------|------------|
| Tambah Testimoni | Nama, rating, isi, upload screenshot WA |
| Edit Testimoni | Ubah semua data, ganti screenshot |
| Hapus Testimoni | Hapus testimoni |

### Pengaturan Web
| Fitur | Keterangan |
|-------|------------|
| Nama Toko | Ubah nama toko di header & footer |
| Hero Title | Ubah judul utama website |
| Hero Deskripsi | Ubah deskripsi hero |
| CTA Title | Ubah judul Call to Action |
| CTA Deskripsi | Ubah deskripsi CTA |
| WhatsApp | Ubah nomor WhatsApp |
| Gambar Hero | Upload gambar hero baru |

### Sosial Media
| Fitur | Keterangan |
|-------|------------|
| WhatsApp | Tombol di header dengan link WA |
| Instagram | Tombol di header & icon di footer |

### Keamanan
| Fitur | Keterangan |
|-------|------------|
| Login Admin | Username: admin / Password: admin123 |
| Ganti Password | Ubah password via panel admin |
| Backup & Restore | Ekspor/impor data JSON |

## 🚀 Cara Menjalankan

1. Download semua file
2. Buka `index.html` di browser
3. Login: `admin` / `admin123`
